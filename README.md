# Sri Vidya — Digital Marketing Manager Portfolio

A responsive, animated personal portfolio website showcasing digital marketing expertise across SEO, SMM, Google Ads, Meta Ads, content strategy, analytics, and website optimisation.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, visual effects and animations
- `script.js` — project database, search, filters, mobile navigation and reveal effects
- `assets/` — add your profile image, resume, and project screenshots here

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `sri-vidya-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
- Add your LinkedIn and GitHub URLs if you want them displayed.
- Confirm project names, locations, services, and website links.
- Add a resume PDF to `assets/` if you want a Download Resume button.
- Add project screenshots or brand assets only where you have permission.

## Accuracy
This portfolio avoids fabricated campaign metrics. Project summaries are intentionally qualitative where verified outcomes were not supplied. Some service categories are broad placeholders and should be edited to reflect the exact work performed.
